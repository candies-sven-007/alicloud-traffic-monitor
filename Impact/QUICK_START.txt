🚀 1分钟快速开始
════════════════════════════════════════════════════════════════════════════

1. 解压项目
   $ unzip alicloud-traffic-monitor-v2.0.0.zip
   $ cd alicloud-traffic-monitor-v2

2. 安装应用 (需要 root)
   $ sudo chmod +x install.sh
   $ sudo ./install.sh install

3. 配置Telegram (可选)
   编辑: sudo vi /etc/alicloud-traffic-monitor.conf
   测试: alicloud-traffic-monitor test

4. 检查状态
   $ alicloud-traffic-monitor status

📋 核心命令
════════════════════════════════════════════════════════════════════════════

  查看流量状态
  $ alicloud-traffic-monitor status

  发送测试通知
  $ alicloud-traffic-monitor test

  运行系统诊断
  $ alicloud-traffic-monitor diagnose

  查看实时日志
  $ tail -f /var/lib/alicloud-traffic-monitor/traffic.log

  管理服务
  $ rc-service alicloud-traffic-monitor {start|stop|restart|status}

  更新软件
  $ sudo ./install.sh update

  卸载软件
  $ sudo ./install.sh uninstall

🔧 配置要点
════════════════════════════════════════════════════════════════════════════

  文件: /etc/alicloud-traffic-monitor.conf

  基本参数:
    INTERFACE="eth0"              # 监控网卡 (默认 eth0)
    SINGBOX_SERVICE="sing-box"    # 受控服务 (默认 sing-box)
    INTERVAL="1"                  # 检查间隔秒数 (1-60)

  Telegram (可选):
    TG_BOT_TOKEN="YOUR_TOKEN"     # 从 @BotFather 获取
    TG_CHAT_ID="YOUR_ID"          # 从 @userinfobot 获取

📞 获取Telegram凭证
════════════════════════════════════════════════════════════════════════════

  1. Bot Token:
     打开: https://t.me/BotFather
     发送: /newbot
     按提示操作，获取 Token

  2. Chat ID:
     打开: https://t.me/userinfobot
     发送: 任意消息
     它会回复你的 Chat ID

  3. 验证:
     $ alicloud-traffic-monitor test
     ✅ 收到测试通知

⚠️  常见问题
════════════════════════════════════════════════════════════════════════════

  Q: 服务启动失败?
  A: 运行诊断: alicloud-traffic-monitor diagnose

  Q: Telegram不工作?
  A: 检查凭证和网络: alicloud-traffic-monitor test

  Q: CPU占用高?
  A: 增加检查间隔: INTERVAL="10"

  Q: 无法读取流量?
  A: 验证网卡名: ip link show

  更多问题见: docs/troubleshooting.md
